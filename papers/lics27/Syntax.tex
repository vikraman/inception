The syntax is parametrised by a set \gls{Data}, a signature (i.e.\ a set of operators \gls{Ops} and an arity function $\glsii{arity} : \gls{Ops} \to \mathbb{N}$) and for each $\gls{op} \in \gls{Ops}$, an interpretation $\OPSEM{\gls{op}} : {\gls{Data}}^{\ARITY{\gls{op}}} \to \gls{Data}$.
